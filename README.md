# Java Maryland — Container Tracking Dashboard

A responsive container tracking dashboard built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Requirements
- npm

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm run start    # Start production server
npm run lint     # Run ESLint (if configured)
```

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form + Zod
- Lucide React

## Notes
- Phase 1 is frontend-only and uses mock data.
- Authentication, database integration, and OpenTrack API synchronization are not implemented.
- Backend integration and production deployment are planned for subsequent phases.
